Activar la aplicación

Esto se hace una sola vez. Se crea la llave de cifrado y la cuenta de administradora. Todos los datos se guardan cifrados en el repositorio.

  1. En GitHub crea un token de acceso fino (Settings → Developer settings → Fine-grained tokens) con acceso solo a este repositorio y permiso Contents: Read and write.
  2. Pégalo abajo. Quedará guardado cifrado; nadie lo ve sin contraseña.

Importar pagos desde Excel

Sube tu archivo .xlsx, .xls o .csv. La primera hoja debe tener una fila de encabezados con columnas como Proveedor, Concepto, Factura, Valor y Vencimiento. Si hay una columna Estado se respeta; si no, todos entran como “Por revisar”.

Subir varias facturas

Selecciona o arrastra las facturas (PDF o imagen). Cada una se lee, se guarda cifrada y queda como pago Por revisar. Las que ya están cargadas (mismo archivo o mismo número de factura y proveedor) se omiten.

    Exportar pagos a Siigo

    Genera el modelo de importación de comprobantes contables con los pagos marcados como pagados en el periodo: un comprobante por factura, débito a la cuenta del proveedor y crédito al banco.

      Token de GitHub

      Si el token vence o lo cambias en GitHub, pega aquí el nuevo.

      Tarea automática de cartera (carpeta FACTURAS DE VENTA)

      Crea un usuario técnico para que la tarea del computador pueda guardar en la app las facturas de venta nuevas. Se descarga un archivo robot-cartera.json con su acceso; guárdalo solo en tu PC y no lo compartas.

      Enlaces para contratistas (cuentas de cobro y anticipos)

      Los contratistas llenan un formulario sin usuario; el envío llega cifrado a un repositorio privado de GitHub que sirve de buzón y la app lo convierte en un pago “Por revisar” con su cuenta de cobro en PDF.

      Lectura de facturas con Claude (opcional)

      Sin clave, la app lee las facturas electrónicas con su lector propio (gratis). Con una clave de la API de Claude (console.anthropic.com) la lectura es más precisa y también funciona con facturas escaneadas y fotos. Cada factura cuesta unos pocos centavos de dólar en tu cuenta de Anthropic. La clave queda guardada cifrada.
